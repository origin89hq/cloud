# Contributing

Follow [Origin89 engineering](https://github.com/origin89hq/engineering/blob/main/CONTRIBUTING.md) and the task-start instructions in [AGENTS.md](AGENTS.md). Shared skills refresh with `just skills-sync`; edit common guidance in engineering and keep service-specific commands here.

Never commit credentials, account data, controller identifiers from real sites, or generated build output. Keep deployment secrets in the organization or environment settings, not in the repository.
